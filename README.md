# WiFiFiles для PocketBook

**WiFiFiles** — файловый менеджер и сетевой сервер для ридеров PocketBook. Приложение позволяет передавать книги и другие файлы между ридером, телефоном и компьютером по Wi-Fi без USB-кабеля и облачных сервисов.

Проект разработан и протестирован на **PocketBook 650** с прошивкой **W650.5.14.798**.

> Текущая версия: **0.7.28** — [скачать с GitHub Releases](https://github.com/gpakoh/WiFiFiles/releases/latest)

Интерфейс приложения доступен на **4 языках**: русском, английском, немецком и французском.

## Возможности

### Передача файлов по QR-коду

На ридере можно выбрать накопитель, конкретную папку и режим доступа, после чего приложение создаст временный QR-код.

После сканирования QR-кода на телефоне открывается адаптивная веб-страница для передачи файлов.

Доступны два режима:

#### Безопасный режим

* отображается только выбранная папка;
* разрешена загрузка файлов на ридер;
* нельзя скачивать, удалять и переименовывать файлы;
* ссылка действует ограниченное время;
* основной пароль WiFiFiles не требуется.

#### Режим редактирования

* загрузка одного или нескольких файлов;
* отображение текущего и общего прогресса;
* скачивание отдельных файлов;
* скачивание всех файлов одним ZIP-архивом;
* переименование;
* удаление отдельных файлов;
* удаление всех файлов в выбранной папке;
* отображение свободного места.

Временная QR-ссылка действует около 20 минут и предоставляет доступ только к выбранной папке.

## WebDAV

WiFiFiles предоставляет полноценный WebDAV-доступ к внутренней памяти и SD-карте.

Поддерживаются:

* просмотр файлов и папок;
* загрузка и скачивание;
* создание папок;
* переименование;
* копирование;
* перемещение;
* удаление файлов и папок;
* работа через Проводник Windows и сторонние WebDAV-клиенты.

Примеры адресов:

```text
http://IP_РИДЕРА:8080/dav/
http://IP_РИДЕРА:8080/dav/internal/
http://IP_РИДЕРА:8080/dav/sd/
```

Для подключения используются логин и пароль, заданные в WiFiFiles.

Логин по умолчанию:

```text
pocketbook
```

### Поддерживаемые методы WebDAV

* `OPTIONS`
* `PROPFIND`
* `GET`
* `HEAD`
* `PUT`
* `MKCOL`
* `MOVE`
* `COPY`
* `DELETE`
* `LOCK`
* `UNLOCK`

Реализована совместимость с `Microsoft-WebDAV-MiniRedir`, используемым службой WebClient в Windows.

## Другие сетевые протоколы

### HTTP

Встроенный браузерный интерфейс для просмотра накопителей, загрузки файлов и управления сервером.

Стандартный адрес:

```text
http://IP_РИДЕРА:8080/
```

### FTP

FTP-сервер для подключения через файловые менеджеры и FTP-клиенты.

Стандартный порт:

```text
2121
```

### SMB2/SMB3

Ридер можно открыть как сетевое хранилище через SMB.

Стандартный порт:

```text
4445
```

Используется нестандартный порт, поскольку запуск приложения не требует системных прав `root`.

## Работа с файлами

WiFiFiles учитывает ограничения старых моделей PocketBook и файловых систем FAT.

Реализованы:

* потоковая загрузка без сохранения больших файлов в системный `/tmp`;
* временные файлы `.part`;
* атомарное завершение загрузки;
* восстановление старого файла при неудачном перемещении или копировании;
* защита от повторной отправки;
* автоматическое переименование конфликтующих файлов;
* корректная обработка длинных и русскоязычных имён;
* защита от выхода за пределы разрешённых каталогов;
* блокировка символических ссылок;
* проверка свободного места.

Если файл с таким же именем и размером уже существует, повторная загрузка пропускается.

Если имя совпадает, но размер отличается, новый файл получает имя вида:

```text
Книга (1).epub
```

## Обновление библиотеки PocketBook

После загрузки, удаления, перемещения или переименования книг WiFiFiles запускает системный сканер библиотеки PocketBook.

Благодаря этому новые книги появляются в библиотеке без ручной перезагрузки устройства.

## Защищённые каталоги

Для предотвращения случайного повреждения системы приложение скрывает и защищает служебные каталоги, включая:

* `system`;
* `applications`;
* `System Volume Information`;
* `LOST.DIR`;
* `.adobe-digital-editions`;
* `.adobe-hidden-files`;
* собственные служебные файлы WiFiFiles.

Ограничения применяются к HTTP, WebDAV, FTP и SMB.

## Интерфейс

Нативная часть приложения написана с использованием PocketBook InkView.

Поддерживаются языки:

* русский;
* английский;
* немецкий;
* французский.

Интерфейс адаптирован для E-Ink-экрана и системной верхней панели PocketBook.

## Журналирование

Диагностические события записываются в один файл:

```text
/mnt/ext1/WiFiFiles.log
```

Повторяющиеся проверки состояния и служебные запросы Windows не засоряют журнал.

## Установка

1. Скопируйте файл `WiFiFiles.app` в каталог:

```text
applications
```

2. Безопасно отключите ридер от компьютера.
3. Откройте раздел приложений PocketBook.
4. Запустите WiFiFiles.
5. При первом запуске установите пароль.
6. Подключите ридер к Wi-Fi.
7. Включите необходимые серверы.

После обновления со старой версии рекомендуется полностью остановить серверы WiFiFiles. При возникновении проблем следует один раз перезагрузить ридер.

Подробная инструкция — в [INSTALL.md](INSTALL.md).

Подтверждённая конфигурация:

## Архитектура

Проект состоит из двух основных частей:

### Нативное приложение

Написано на C с использованием InkView.

Отвечает за:

* интерфейс на ридере;
* управление Wi-Fi;
* настройку серверов;
* выбор папок;
* создание QR-кодов;
* запуск и остановку серверной части;
* отображение состояния.

### Серверная часть

Написана на Go и собирается для ARM.

Отвечает за:

* HTTP;
* WebDAV;
* FTP;
* SMB2/SMB3;
* авторизацию;
* файловые операции;
* временные QR-сессии;
* потоковую загрузку;
* обновление библиотеки PocketBook.

ARM-сервер встраивается непосредственно в `WiFiFiles.app` и при запуске извлекается во временное хранилище.

## Сборка

Для сборки требуется Linux и подходящий ARM toolchain для PocketBook.

Базовая команда:

```bash
./build.sh build
```

Результатом является файл:

```text
WiFiFiles.app
```

Перед выпуском релиза рекомендуется:

```bash
go test server.go mobile.go webdav.go qr.go \
  server_test.go mobile_test.go webdav_test.go \
  qr_test.go portable_upload_test.go
```

Из-за присутствия C-файлов обычная команда `go test ./...` может потребовать отдельной настройки CGO.

## Ограничения

* приложение пока протестировано только на PocketBook 650;
* скорость передачи ограничена производительностью ридера и Wi-Fi;
* SMB использует порт `4445`, а не стандартный `445`;
* Basic-аутентификация по обычному HTTP не используется;
* WebDAV работает через Digest-аутентификацию;
* HTTPS пока не поддерживается;
* системные папки намеренно скрыты;
* приложение не заменяет резервное копирование данных.

## Безопасность

WiFiFiles предназначен прежде всего для использования в доверенной локальной сети.

Не рекомендуется:

* открывать порты приложения в интернет;
* использовать общедоступные Wi-Fi-сети;
* устанавливать простой пароль;
* оставлять серверы включёнными без необходимости.

QR-ссылки являются временными и ограничены выбранной папкой, однако доступ к ним также следует предоставлять только доверенным устройствам.
