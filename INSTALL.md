# Установка WiFiFiles 0.7.28 на PocketBook 650

1. Подключите PocketBook к компьютеру по USB.
2. Откройте внутреннюю память ридера.
3. Скопируйте `WiFiFiles.app` из этого репозитория в папку `applications`.
4. Подтвердите замену предыдущего `WiFiFiles.app`.
5. Безопасно отключите ридер и запустите WiFiFiles.

## Обновление с предыдущей версии

Язык, логин, собственный пароль и выбранные порты сохраняются. Достаточно заменить файл `WiFiFiles.app`.

Если в старой версии оставался заводской пароль, перед запуском служб WiFiFiles попросит установить новый. Это не ошибка обновления, а защита от запуска доступного всем сервера.

## Первое подключение к Wi-Fi

При запуске WiFiFiles сначала проверяет, подключён ли ридер к Wi-Fi.

- Если подключение и IP-адрес уже есть, приложение сразу откроет главный экран.
- Если ридер подключён, но IP ещё не выдан, Wi-Fi не перезапускается: приложение ждёт адрес и автоматически продолжает работу.
- Если подключения нет, WiFiFiles один раз выключит и включит Wi-Fi, затем попробует подключиться к сохранённой точке доступа.
- Для выбора другой сети нажмите «Настройки Wi-Fi».

После подключения дополнительное ручное обновление не требуется. Если IP будет получен позднее, приложение обнаружит его автоматически.

## Первый запуск служб

Логин по умолчанию — `pocketbook`. Перед первым запуском HTTP, WebDAV, FTP или SMB задайте собственный пароль в приложении. Один пароль используется для всех включённых сетевых служб.

## Полноценный WebDAV

После запуска HTTP + WebDAV откройте в браузере адрес `http://IP_РИДЕРА:ПОРТ/dav/`. Страница WebDAV теперь является полноценным файловым менеджером: можно переходить по папкам внутренней памяти и SD-карты, загружать несколько файлов с прогрессом, создавать папки, скачивать, переименовывать, перемещать, копировать и удалять объекты.

Тот же адрес можно подключить в Windows, Linux, macOS, Android или другом WebDAV-клиенте как сетевое хранилище. Стандартные операции чтения и записи работают через PROPFIND, PUT, MKCOL, MOVE, COPY и DELETE. Папки `system` и `applications` скрыты и защищены.

Для Windows указывайте адрес обязательно с реальным IP и завершающим слешем, например `http://192.168.1.207:8080/dav/`. При первичной проверке Windows может не запрашивать пароль сразу: мастер сначала проверяет корень, затем логин `pocketbook` и установленный пароль понадобятся при открытии накопителя.

### Подключение WebDAV в Windows (0.7.22)

Для наиболее надёжного подключения добавляйте конкретный накопитель:

```text
внутренняя память: http://IP_РИДЕРА:8080/dav/internal/
SD-карта:          http://IP_РИДЕРА:8080/dav/sd/
```

Общий адрес `http://IP_РИДЕРА:8080/dav/` показывает оба накопителя после авторизации. Windows должен запросить логин `pocketbook` и установленный в WiFiFiles пароль при первом подключении. Если ранее было создано гостевое расположение, удалите его и перезапустите службу WebClient перед новой попыткой.

## Передача с телефона по QR-коду

На главном экране нажмите «ПО QR». Если HTTP-сервер ещё не запущен, WiFiFiles запустит его автоматически после проверки пароля. Затем:

1. Выберите память ридера или карту SD.
2. Откройте нужную папку. Кнопка «Вверх» возвращает на уровень выше, а «Пред.» и «След.» листают длинный список папок.
3. Нажмите «Сохранять в эту папку».
4. Выберите режим QR-доступа:
   - безопасный — только просмотр списка и отправка книг;
   - редактирование — загрузка, скачивание, переименование и удаление.
5. Отсканируйте QR-код телефоном.
6. Выберите одну или несколько книг и начните передачу.

Оба режима ограничены выбранной папкой. Телефон не может перейти в родительский или соседний каталог. В безопасном режиме операции скачивания, удаления и переименования сервером отклоняются, даже если вручную открыть адрес операции.

При передаче нескольких книг формируется очередь. Каждая книга получает отдельное подтверждение, отображаются текущий и общий прогресс. После ошибки кнопка «Повторить неудавшиеся» отправляет только проблемные позиции. Повтор с тем же идентификатором не создаёт дубликат, если файл уже был успешно принят.

Файл с совпадающим именем и размером пропускается как уже существующий. Если имя совпадает, а размер отличается, новый файл сохраняется с номером. На странице также показывается свободное место выбранной памяти.

## Безопасная запись файлов

Крупные файлы не сохраняются в системный `/tmp`. WiFiFiles читает входящий поток небольшими блоками и сразу пишет `.part` в выбранную папку. Поэтому размер временного раздела PocketBook не ограничивает очередь PDF; ограничением остаётся только свободное место выбранной внутренней памяти или SD-карты.

Во время передачи HTTP, QR-кодом или FTP файл сначала сохраняется как временный `.part`. Итоговое имя присваивается только после успешной записи. Если связь оборвалась, незавершённый файл не должен индексироваться как готовая книга.

Передача через HTTP, QR-код и WebDAV также проверяет, достаточно ли свободного места. Небольшой резерв оставляется для работы системы и базы библиотеки.

## Обновление библиотеки после передачи

После успешной загрузки EPUB, FB2, PDF или другого поддерживаемого документа WiFiFiles через несколько секунд запускает штатное обновление библиотеки PocketBook. На экране может кратковременно появиться системное сообщение «Обновление». Затем книга должна появиться в разделе «Новые».

Функция действует для передачи по QR-коду, HTTP, WebDAV, FTP и SMB. Несколько файлов, отправленных подряд, объединяются в одно обновление.

## Открытые Wi-Fi-сети

Если системный сетевой менеджер сообщает, что сеть не защищена паролем, WiFiFiles покажет отдельное предупреждение. Не передавайте файлы через общественную открытую сеть; подключитесь к доверенной защищённой точке доступа.

## Инструкции и размер шрифта

Откройте пункт «Инструкции» и выберите HTTP, WebDAV, FTP или SMB. Приложение подставит текущий IP ридера и выбранные порты.

Между кнопками «Назад» и «Язык» находится настройка шрифта: 90%, 100% или 115%. Карточки и страницы формируются заново для выбранного размера. Когда текст помещается на одном экране, вторая страница не создаётся.

## Верхняя системная панель

WiFiFiles не отключает верхнюю системную панель PocketBook, поэтому она остаётся доступной во время работы приложения.

## Обновление E-Ink

Обычные переключатели обновляют только изменённую строку. Если после множества частичных обновлений появились следы старого текста, нажмите «Обновить экран». Кнопка выполнит полную очистку и не сбросит несохранённые настройки.
